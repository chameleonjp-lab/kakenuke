# カケヌケ / KAKENUKE

**時間をあやつるエンドレス・アーケードシューティング**
A time-control endless arcade shooter for the browser, built with **TypeScript + Vite + Phaser 3**.

> オリジナル実装です。名称・ロゴ・キャラクター・アート・音・UI はすべて独自のもので、
> 抽象的な低ポリ風プリミティブ（円・三角・矩形など）だけで描画しています。

---

## コアメカニクス — 「移動量＝時間進行量」

このゲームの心臓部は、**プレイヤーの入力速度がゲーム内時間を制御する**ことです。

| 入力 | ゲーム内時間 |
|------|--------------|
| 指を止める | 敵・敵弾・自弾・武器発射・ボス・アイテムが **完全停止** |
| ゆっくり動かす | **スローモーション** |
| 速く動かす | **早送り** |

ただし、画面下から迫る黒い **デッドライン（崩壊領域）だけは実時間で進み続けます**。
時間を止めても背後の闇は止まらないため、止まりっぱなしの完全安全はありません。
デッドラインに追いつかれたらゲームオーバーです。

技術的には毎フレーム以下を計算しています（`src/game/TimeController.ts`）:

```
inputSpeed  = |pointerDelta| / realDt
timeScale   = clamp((inputSpeed - DEADZONE) / REFERENCE_SPEED, 0, MAX_TIME_SCALE)  // 平滑化
scaledDt    = realDt * timeScale
```

- **scaledDt** で更新: 敵・敵AI・敵弾・自弾・武器発射・ボス・アイテム
- **realDt** で更新: デッドライン・UI・入力・ポーズ/リザルト

## 操作方法

### タッチ / マウス
- 画面を **ドラッグ** してキャラクターを移動。ドラッグの向きに動き、**ドラッグの速さがゲーム内時間の速さ**になります。
- 指を離す、または止めると時間が止まります。
- 攻撃は **自動**。時間が進んでいる間だけ発射されます。
- 右上の **⏸ ポーズボタン**（ポーズは「時間停止」とは別物です）。

### キーボード（フォールバック）
- **WASD / 矢印キー** … 移動（時間 = 等速）
- **Shift** 押しながら … スロー移動（時間 = 0.35倍）
- キー未入力 … 時間停止
- **P** … ポーズ

## ゲームルール

- HP は **1**。敵・敵弾・デッドライン・凍結中の敵に触れると即ゲームオーバー。
- クリアやエンディングはありません。**1プレイでどこまで前進し、どれだけスコアを稼げるか**を競います。
- 前進するほどスコアが伸び、敵・ボス撃破や武器箱取得でも加算されます。
- **青いオブジェクト** → 破壊すると武器箱（ランダム武器）。同じ武器を再取得すると **レベルアップ**（累積強化、上限なし）。取得武器はそのプレイ中のみ有効。
- **緑のオブジェクト** → コイン。コインは保存され、キャラ購入・POD・コンティニューに使えます。
- 敵は **色で挙動が分かります**: 黒=直進 / 橙=追尾 / 紫=蛇行・高速 / 緑=コイン / 青=武器。
- 一部の敵弾は **他の敵にも当たってダメージ** を与えます（ボスには 50%）。
- ボスは巨大・高耐久・追尾型で、倒すまで追ってきます。

### コンティニュー
- **Normal のみ、1プレイ1回** だけコインでコンティニュー可能。
- コンティニュー後は **約3秒間無敵**、デッドラインが後方へ押し戻されます。
- **Hardcore ではコンティニュー不可**。

---

## キャラクター

- 初期キャラ **カケヌケ** は無料。当たり判定が小さく練習向け（標準ショットのみ）。
- 追加キャラはコインで購入して出撃でき、当たり判定・見た目サイズ・初期武器・感度が異なります。
- **POD ROLL（◇100）** … ランダムに 3 体の候補を提示し、その中から 1 体を選んで出撃できます。
- 累計スコアに応じて選べるキャラの幅（POD 帯）が広がります。

---

## Hardcore モード

- **BEST（トップスコア）10000 以上** で解放されます。
- デッドライン高速化 (×1.35)、敵密度増 (×1.4)、武器箱出現率減 (×0.75)、コイン増 (×1.2)、スコア倍率 ×1.25、ボス初出現が早い、コンティニュー不可。

## セットアップ / 実行

```bash
npm install     # 依存関係のインストール
npm run dev     # 開発サーバ（http://localhost:5173）
npm run build   # 型チェック + 本番ビルド（dist/ に出力）
npm run preview # ビルド結果をローカルプレビュー
```

- 論理解像度 **1080 × 1920（縦画面）**、`Scale.FIT` で端末サイズにレスポンシブ対応。
- モバイルのタッチ、デスクトップのマウス、キーボードすべてでプレイ可能です。

## 保存データのリセット

進行データは `localStorage` に保存されます:

| キー | 内容 |
|------|------|
| `tl_clone_bestScore` | 最高スコア |
| `tl_clone_totalCoins` | 累計コイン |
| `tl_clone_cumulativeScore` | 累計スコア（POD 解放に使用） |
| `tl_clone_hardcoreUnlocked` | Hardcore 解放フラグ |
| `tl_clone_settings` | 音量・感度・振動設定 |

**リセット方法:**
- ゲーム内 **Settings → RESET SAVE DATA**（スコア・コイン・解放をすべて消去）。
- または、ブラウザの開発者ツールで `localStorage.clear()` を実行。

## デバッグモード

ゲーム中に **バッククォート（`` ` ``）** を押すとデバッグモードを切り替えます。ON の間:

- ヒットボックス表示 / timeScale・敵数・弾数・難易度・デッドライン速度などのパネル表示
- **B** … ボス強制出現 / **I** … 無敵トグル / **H** … ヒットボックス表示
- **C** … コイン +500 / **R** … 保存データリセット

## プロジェクト構成

```
src/
  main.ts                     # Phaser 起動・シーン登録
  config/                     # データ駆動の定義
    progression.ts            #   定数・難易度曲線・デッドライン・経済
    weapons.ts                #   武器 13 種と出現重み
    enemies.ts                #   敵 30 種・色→挙動マッピング・出現プール
    characters.ts             #   キャラ定義
  game/
    TimeController.ts         # 入力速度 → timeScale / 移動量
    GameScene.ts              # メインループ（scaledDt / realDt の分離）
    Player.ts                 # プレイヤー（HP1・移動・無敵）
    Deadline.ts               # 実時間で迫る崩壊領域
    Shapes.ts                 # 低ポリ風描画ヘルパー・パーティクル
    weapons/
      WeaponSystem.ts         # 所持武器・発射・ガードビット・ドローン
      Projectile.ts           # プール式弾（自弾・敵弾共通）
    enemies/
      Enemy.ts                # 敵の挙動（色ベース）
      EnemySpawner.ts         # チャンク生成・デスポーン
    bosses/
      Boss.ts                 # ボス（追尾・射撃・ダッシュ）
    items/ItemSystem.ts       # コイン（吸引）・武器箱
    economy/SaveData.ts       # localStorage 保存
    ui/Hud.ts, UiKit.ts       # HUD・メニュー部品
    scenes/                   # Boot / Title / ModeSelect /
                              # CharacterSelect / Settings / Result
```

各種チューニング値はすべて `src/config/` に集約しているので、ロジックに触れず調整できます。
